BetaTest Flow

Captura feedback beta estructurado, exporta reportes ejecutivos y transforma ruido de QA en acciones claras para publicar con confianza.

Instalacion rapida Ver demo offline

Problema

En betas reales, el feedback suele quedar disperso en chats, capturas y notas aisladas. Eso retrasa fixes criticos y vuelve subjetiva la decision de publicar.

Solucion

BetaTest Flow estandariza la captura de reportes en Flutter y genera salidas operativas: Executive Report, Release Decision, Beta Confidence Score, Plan de accion 48h y AI Correction Prompt.

Como funciona

  1. Integras el SDK en tu app Flutter y habilitas el boton de feedback.
  2. Recolectas reportes estructurados por campana en Firestore o JSON offline.
  3. Ejecutas export y obtienes un resumen ejecutivo con decision y plan de accion.

Vista del informe ejecutivo

Executive Report

Resumen operativo de severidad, resultados, pantallas y observaciones UX.

Release Decision

Estado GO / GO CON CONDICIONES / NO-GO con razon y condiciones de salida.

Beta Confidence Score

Score global y subscores para estabilidad, usabilidad y release readiness.

Plan de accion 48h

Priorizacion P1-P5 con accion sugerida y criterio de validacion por item.

AI Correction Prompt

Prompt listo para ejecutar correcciones guiadas por evidencia real de beta.

Instalacion rapida

Agrega la dependencia del SDK en la app host y sincroniza paquetes.

dependencies:
  betatest_flow:
    path: ../betatest_flow

flutter pub get

Demo offline

Genera reportes sin depender de Firestore usando el fixture oficial del proyecto.

dart run tools/export_beta_reports.dart \
  --input-json example/data/sample_beta_reports.json \
  --out-dir exports/demo
